# Certifications Section & CV Data Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a public "Certifications" grid section to the homepage, split the existing `Certification` model into true certifications vs. career awards/distinctions, and sync `ExperienceSeeder`, `EducationSeeder`, and `CertificationSeeder` with the owner's updated CV (`docs/CV_Abdoul_Aziz_ZOROM_12_EN_AI_engineer_and_full_stack_developer.pdf`).

**Architecture:** A new `Award` model/table (mirroring `Certification`'s structure: translatable title, issuer, date, optional URL, no media) holds career awards and entrepreneurship-programme distinctions, managed via a Filament resource mirroring `CertificationResource`. `CertificationSeeder` keeps only verifiable certifications and gains 4 new Stanford/DeepLearning.AI entries. A new Blade section `certifications-grid.blade.php` (badge image + title + issuer + date + "Verify" link, card grid, mirrors the visual conventions of `skills.blade.php`) replaces `certifications-marquee.blade.php` in all 5 home layouts, including `gerold-01` (the currently active layout, which never had the marquee wired in — this is why certifications never appeared on the live site). `ExperienceSeeder` and `EducationSeeder` are corrected against the new CV. `Award` is **not** wired into the resume/PDF export or any public section — out of scope per this plan; only `Certification` continues to feed `ResumeBuilder`.

**Tech Stack:** Laravel 13, Filament v5 (`Filament\Schemas\*` namespace), Spatie Translatable, Pest 4.

**Spec:** This plan's own Goal/Architecture sections above (no separate spec doc — requirements were gathered via direct conversation with the site owner and cross-checked against the CV PDF).

## Global Constraints

- No `_translations` tables — translatable fields use JSON columns + `HasTranslations`.
- Every admin CRUD surface is a Filament Resource under `app/Filament/`, using `Filament\Schemas\*` (v4+/v5 namespace), never `Filament\Forms\Components\*` directly for schema composition.
- No hardcoded UI strings — always `__()`, keys added to both `lang/en/*.php` and `lang/fr/*.php`.
- Every change must be programmatically tested (`php artisan test --compact --filter=...`).
- Run `vendor/bin/pint --dirty --format agent` after any PHP file changes, before considering a task done.
- Do not generate placeholder/lorem-ipsum seed data — all seed data must come from the real CV content already extracted in this conversation.
- Do not touch the resume/PDF export pipeline (`app/Services/Resume/ResumeBuilder.php`, `resources/views/resume/`) — `Award` stays out of it.

```php
<?php

namespace App\Models;

use Database\Factories\AwardFactory;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Spatie\Translatable\HasTranslations;

class Award extends Model
{
    /** @use HasFactory<AwardFactory> */

    use HasTranslations;

    protected $fillable = [

        'url',
    ];

    /** @return array<string, string> */

    {
        return [
            'awarded_at' => 'date',
        ];
    }
}
```

```php
namespace App\Filament\Resources\Awards\Schemas;

use Filament\Forms\Components\DatePicker;
use Filament\Forms\Components\TextInput;
use Filament\Schemas\Components\Section;
use Filament\Schemas\Schema;

class AwardForm
{
    public static function configure(Schema $schema): Schema
    {
        return $schema
            ->components([
                Section::make()
                    ->columns(2)
                    ->schema([
                        TextInput::make('title')
                            ->required()
                            ->columnSpanFull(),
                        TextInput::make('issuer')
                            ->required(),
                        DatePicker::make('awarded_at')
                            ->native(false),
                        TextInput::make('url')

                            ->columnSpanFull(),

}
```

- [ ] **Step 3: Replace the generated table**

Edit `app/Filament/Resources/Awards/Tables/AwardsTable.php`:

```php
<?php

namespace App\Filament\Resources\Awards\Tables;

use Filament\Actions\BulkActionGroup;
use Filament\Actions\DeleteBulkAction;
use Filament\Actions\EditAction;
use Filament\Tables\Columns\TextColumn;
use Filament\Tables\Table;

class AwardsTable
{
    public static function configure(Table $table): Table
    {
        return $table
            ->defaultSort('awarded_at', 'desc')
            ->columns([
                TextColumn::make('title')
                    ->searchable()
                    ->sortable(),
                TextColumn::make('issuer')
                    ->searchable()
                    ->sortable(),
                TextColumn::make('awarded_at')
                    ->date('M Y')
                    ->sortable(),
                TextColumn::make('url')
                    ->url(fn ($record) => $record->url)
                    ->toggleable(isToggledHiddenByDefault: true),
                TextColumn::make('created_at')
                    ->dateTime()
                    ->sortable()
                    ->toggleable(isToggledHiddenByDefault: true),
            ])
            ->recordActions([
                EditAction::make(),
            ])
            ->toolbarActions([
                BulkActionGroup::make([
                    DeleteBulkAction::make(),
                ]),
            ]);
    }
}
```

```php
<?php

namespace App\Filament\Resources\Awards;

use Filament\Resources\Resource;
use Filament\Schemas\Schema;
use Filament\Support\Icons\Heroicon;
use Filament\Tables\Table;
use UnitEnum;

class AwardResource extends Resource
{
    protected static ?string $model = Award::class;

    protected static string|BackedEnum|null $navigationIcon = Heroicon::OutlinedStar;

    protected static string|UnitEnum|null $navigationGroup = 'Career';

    protected static ?int $navigationSort = 5;

    public static function form(Schema $schema): Schema
    {
        return AwardForm::configure($schema);
    }

    public static function table(Table $table): Table
    {
        return AwardsTable::configure($table);
    }

    public static function getRelations(): array
    {
        return [];
    }

    public static function getPages(): array
    {
        return [
            'index' => ListAwards::route('/'),
            'create' => CreateAward::route('/create'),
            'edit' => EditAward::route('/{record}/edit'),
        ];
    }
}
```
